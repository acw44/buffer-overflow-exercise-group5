# Buffer Overflow Code Review

1. This is a group exercise.

2. **Each student**
   1. Download the code to review and the Code Review Template contained in this [zip file](#).
   2. Review the code, looking for coding issues, and document them using the Code Review Document:
      1. Poor C++ programming standards.
      2. Security issues or possible execution issues.

3. **Group**
   1. Review the code, addressing each student's issues.
   2. Discuss the issues found by each student.
   3. Determine whether each issue needs to be documented.
   4. Consolidate the issues found by each student into a single group Code Review Document.
   5. Discuss and make recommendations to repair the code.
   6. Rewrite the code to address all issues.

4. **Submission** — zip file: `<groupnumber>overflow.zip`
   1. Completed Code Review Document.
   2. Rewritten code.
