# buffer-overflow-exercise-group5
Secure Software Development - 82941 CEN4078 Group 5

Buffer Overflow Code Review

This is a group exercises.
Each student:
Download the Code (cpp file) to Review and Code Review Template (doc).
Reviews the code looking for coding issue and document using the Code Review Document
- Poor C++ programming standards
- Security issues or possible execution issues. 

Group:
Review the code addressing each students issues.
Discuss the issue found by each students
Determine if the issue needs to be documented.
Consolidate the issues each student found into a single group Code Review Document.
Discuss and make recommendation to repair the code.
Rewrite the code to address all issues.

Submission - zip file - <groupnumber>overflow.zip
Completed Code Review Document
Rewritten code.
